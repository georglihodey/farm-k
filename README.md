# FARM-K: Family-Aware Robustness Model for K

**FARM-K** — это аналитический конвейер на языке R, предназначенный для надежного анализа генетической структуры популяций, постобработки результатов программ ADMIXTURE/fastSTRUCTURE и оценки стабильности кластеров при различных порогах адмиксии и значениях K.

Метод был специально разработан для преодоления стохастического переразбиения кластеров и разделения макропопуляционной предковой структуры от семейной субструктуры в популяциях сельскохозяйственных животных с интенсивной селекцией (таких как голштинизированный молочный скот).

---

## 🚀 Основные возможности

* **Консенсусное выравнивание (`align_and_average_k`)**: Выравнивает матрицы нескольких независимых прогонов с использованием метрики сходства CLUMPP и метода решения задачи о назначении (`clue::solve_LSAP`) для построения стабильных консенсусных $Q$-матриц.
* **Порог робастности (интеграция с `ipADMIXTURE`)**: Итеративно оценивает стабильность кластеров в широком диапазоне порогов доли примеси (`admixRatioThs` от $0.30$ до $0.00$).
* **Отслеживание стабильности кластеров (ARI и индекс Жаккара)**: Вычисляет скорректированный индекс Рэнда (ARI) и матрицы сходства Жаккара для выявления структурных переходов, отделяя истинные макропопуляционные разделения от семейного «шума».
* **Выделение ядерных индивидуумов**: Определяет стабильных «ядерных» особей, принадлежность которых к кластерам остается неизменной при строгих порогах.
* **Межмодельный анализ стабильности по K**: Отслеживает трансформацию, разделение или слияние кластеров при увеличении значений $K$.

## 🛠 Системные требования и зависимости

Для запуска скрипта убедитесь, что в вашем окружении R установлены следующие библиотеки:

```R
install.packages(c("ggplot2", "tidyr", "dplyr", "viridis", "stringr", "clue", "mclust"))

```

Необходимые пакеты R:

* `ipADMIXTURE`

* `mclust` (для расчета Adjusted Rand Index)


* `ggplot2`, `viridis`, `tidyr`, `dplyr`, `stringr` (для обработки данных и визуализации)


* `clue` (для решения оптимизационной задачи LSAP)



---

## 📂 Структура входных данных

Конвейер ожидает стандартные результаты популяционной геномики:

1. Файл `.fam`, содержащий идентификаторы образцов и информацию о группах.
2. Сводные файлы результатов `fastSTRUCTURE` или `pong` (`result_summary.txt`, `pong_filemap.txt`), содержащие индивидуальные доли предковых компонентов ($Q$-матрицы) для различных прогонов и значений $K$.

## ⚙️ Краткое руководство по использованию

1. **Задайте рабочую директорию и загрузите данные:**
```R
setwd('PATH_TO_DIR')
# Загрузите .fam и распарсите результаты pong/fastSTRUCTURE, как показано в FARM-K.R

```


2. **Запустите консенсусное выравнивание:**
Скрипт автоматически считывает основные режимы (major modes) из результатов `pong`, выравнивает столбцы относительно эталонного прогона и генерирует усредненные консенсус-матрицы $Q$ для каждого $K$.
3. **Выполните сетку расчетов робастности и кластеризации:**
```R
k_values <- 2:14 
ths_values <- seq(0.30, 0.00, by = -0.01)
# Цикл выполняет итерации ipADMIXTURE по всей сетке параметров

```


4. **Генерация диагностических графиков и визуализаций:**
* **Динамика числа кластеров** при изменении строгости порогов адмиксии.


* **Теплокарты ARI** для оценки внутренней согласованности кластеризации.


* **Графики траекторий Жаккара**, отслеживающие сохранность кластеров.



---

## 📊 Выходные файлы

* `межмодельная_стабильность.txt`: Метрики переходов и стабильности кластеров между различными $K$.


* `стабильные_кластеры_сводные_результаты.txt`: Сводка неизменяемых, высокостабильных кластеров ($\text{Jaccard} \ge 0.85$).


* `список_всех_образцов_стабильных_для_клатера.txt`: Отфильтрованный список ядерных особей, отнесенных к робастным кластерам по всем оцененным значениям $K$.
